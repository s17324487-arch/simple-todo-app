# 変更履歴

このファイルの書き方:

- いちばん上の `## [版]` が、`js/version.js` の `GAME_VERSION` と `package.json` の `version` と同じであること（`npm run check` が確かめる）。
- ver2 の開発中は `## [2.0.0-dev] - 開発中` の節に、PR ごとに1〜数行ずつ追記する。リリースのときに `## [2.0.0] - 日付` にする。
- 書く分類: 追加 ／ 変更 ／ 修正 ／ 削除。遊ぶ人に関係する変更を、わかる言葉で書く。

## [2.0.0-dev] - 開発中

### 変更

- 戦闘メニューをコンパクトにし、技・道具を選んでも3人のHPが隠れない配置に修正。

- ver2 の開発を開始。タイトルと せっていの表示を ver 2.0.0-dev に更新。これまでのセーブはそのまま使えます。

## [1.0.0] - 2026-09-27

最初の完成版（ver1）。git タグ `v1.0.0`。

### 追加

- わんこ・がちゃん・ごじ の3人が いつも一緒に行動する、スマホ向けの ほのぼの育成・着せ替え・冒険ゲーム。
- おうち: ごはん（好物・苦手あり）・なでる・あそぶ（かくれんぼ・ボールあそび）・ねる・きがえ・もようがえ。おなか・ごきげんはリアル時間で減る。
- 着せ替え: 5部位 約45種類。3人の体型・向き・ポーズに合わせて描く。ごじは体の色（ソフト／ダーク）を選べる。
- 部屋作り: 家具24種・壁紙8種・床6種。「いごこち」で ごきげんの減り方が変わる。
- お店のおてつだい（おみせっち風ミニゲーム）: クレープやさん・はいしゃさん・パンやさん・おはなやさん。評価 ◎○△×、チップ、評判でお店が Lv5 まで成長。
- お買い物: ようふくやさん（試着つき）・かぐやさん・スーパー。
- 上から見下ろす町と外の世界（ぽかぽかはらっぱ・どんぐりのもり・キラキラどうくつ）、宝箱、町の人との会話。
- 3人パーティのターン制バトル: とくぎ（キャラごとに4〜5種）・どうぐ・なかよしトリオアタック・ボス「キングプルン」。
- 時間帯で町の色が変わる（夜は街灯）。WebAudio の効果音と BGM。PWA（ホーム画面に追加・オフライン）。
- 開発の仕組み: バージョンの一元管理（`js/version.js`）、セーブ形式の番号と移行（`Save.SCHEMA` / `migrate()`）、
  テスト用 API `PokaDebug`、静的チェック `npm run check`、Playwright のスモークテスト `npm test`、素材プレビュー `tools/preview.html`、
  GitHub Actions の自動テスト（game-test）と リリースの自動作成（release）、引き継ぎ文書（`AGENTS.md`・`docs/`）。

### 修正

- はらっぱ と もり の間のワープ先が 木の上になっていたのを直した。
- 高解像度（3倍）の画面で キャラが少しぼやけていたのを直した。
- 名前の変更を 画面内の入力ダイアログにした（`prompt()` が使えない環境でも変えられる）。
- 名前に HTML の記号（`<` `>` など）を入れると 表示が崩れることがあったので、記号を取りのぞくようにした。
