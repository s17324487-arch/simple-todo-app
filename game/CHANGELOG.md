# 変更履歴

このファイルの書き方:

- いちばん上の `## [版]` が、`js/version.js` の `GAME_VERSION` と `package.json` の `version` と同じであること（`npm run check` が確かめる）。
- ver2 の開発中は `2.0.0-dev` の節に、PR ごとに1〜数行ずつ追記する。リリースのときに `2.0.0` にして日付を書く。
- 書く分類: 追加 ／ 変更 ／ 修正 ／ 削除。遊ぶ人に関係する変更を、わかる言葉で書く。

## [2.0.0-dev] - 開発中

- シティにびようしつを開店。見本の輪郭をなぞるカット、3か所のドライヤー、リボン選びのおてつだいを追加。はみ出しと乾かし残しも採点。専用の鏡・カット椅子・道具ワゴン・音楽と、店員からのリボン購入に対応。
- 設定からセーブを文字列・ファイルへ書き出し、確認して読み込めるようにしました。おかね・服・部屋・レベル・中断中の有料パズルをまとめて保持。壊れたデータや保存失敗では現在のセーブを置き換えません。

- ぽかぽかタウンのパン屋の隣にケーキ屋を開店。店内のショーケース・飾り付け台・店員・専用BGMと、土台・クリーム・果物・ろうそくを作るおてつだいを追加。Lv1〜5で注文が複雑になり、高レベルでは覚えて作ります。

- おてつだいの処理をお店ごとのファイルへ整理。今後のお店追加に備え、遊び方・採点・報酬・セーブはそのまま保持。

- 平和台に見本の住民8人と通行人5人を追加。信号・電車・噴水・旗・ブランコを動かし、夜は街灯・自販機・灯籠・ちょうちんが光る。

- 平和台を見本v0.2の64×68マスへ更新。駅・商店街・住宅地・公園と、点字ブロック・側溝・駐車場・電線を元の配置で描画。既存のお店・交通・宝箱・おかねを維持し、古い座標が建物内なら駅前へ戻す。

- 平和台の残りA・B素材81種も元のSVGから移植。住宅・車・公園・線路・背景を含む全107種がゲームの描画素材として利用可能。

- 平和台の優先度S素材26種を見本のSVGからそのまま移植。駅舎・商店・銭湯・神社・小物を有限の描画一覧に登録し、元のSVGとの一致を検査。

- なかよしパズルを80コインのスコアアタックへ変更。無料練習、直線・L字・輪・長鎖の特殊消去、コンボとフィーバー、消すと延びる時計と段階的な難易度を追加。1,200〜45,000点で光る限定家具5品を初回獲得できます。
- パズルは盤面・残り時間を中断保存して追加料金なしで再開。参加料・景品は重複を防いで即時保存し、旧所持金・アイテム・部屋・従来の店の記録を維持。

- 9種類のおみせに、3にんで歩ける店内と店員を追加。洋服のラックと試着室、家具の展示、食品棚、調理場、診察室、花の作業台、パズル台、配送所をそれぞれ描き分けました。
- 買い物は店員に話しかけて開始。パン屋・クレープ屋・花屋にも既存商品を置き、おてつだい後は店内へ戻ります。買った品物とおかねはすぐ保存し、店内での再読み込みは入口の外から再開します。

- 追加: 設定のバージョン表示を7回連続タップすると管理者コマンドを表示。所持金を99,999に設定、3人のHP・SP全回復、おなか・ごきげん100に対応。実行確認後に保存し、メニューを閉じると入口は再び隠れます。

- 追加: 「おへや」から、今いる部屋を6,000コインで床面積2倍に拡張できます。各部屋1回ずつ。配置・家具・壁紙・床を引き継ぎ、広がった床にも家具を置けます。

- 修正: ごじの涙が、口の横ではなく頭の左右の目から流れるように位置を修正。横向きでも目の位置に合わせます。

- 町・建物・お店・戦闘・結果の全32曲を、ピアノ/エレクトリックピアノ・弦の音・柔らかいベースとドラムで編曲。町と店ごとのテンポ、和音、リズム、短い残響を追加しました。曲切替時の余分な音を止め、背景タブから戻ったときの音の重なりも防ぎます。音のオン/オフ設定とプレイデータはそのまま使えます。

- ぽかぽかタウン・シティ・港・空港の街区を作り直し。町ごとの建物と店先の品物、歩道・路地・街灯、海へ延びる桟橋、滑走路と展望デッキを追加。既存のお店・ミニゲーム・交通・季節イベントと、おかね・取得品を維持。古いセーブ位置が新しい建物などに重なる場合は近くの通れる場所から再開します。

### 変更

- 簡単なお店の報酬を抑え、複雑な新作と高難度の報酬を増加。バトルの基本コインを25%増やし、複数の敵には追加報酬。失敗・放置の評価×は報酬0。
- 戦闘メニューをコンパクトにし、技・道具を選んでも3人のHPが隠れない配置に修正。

- ver2 の開発を開始。タイトルと せっていの表示を ver 2.0.0-dev に更新。これまでのセーブはそのまま使えます。
