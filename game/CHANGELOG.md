# 変更履歴

このファイルの書き方:

- いちばん上の `## [版]` が、`js/version.js` の `GAME_VERSION` と `package.json` の `version` と同じであること（`npm run check` が確かめる）。
- ver2 の開発中は `2.0.0-dev` の節に、PR ごとに1〜数行ずつ追記する。リリースのときに `2.0.0` にして日付を書く。
- 書く分類: 追加 ／ 変更 ／ 修正 ／ 削除。遊ぶ人に関係する変更を、わかる言葉で書く。

## [2.0.0-dev] - 開発中

- おうちを左右の壁・木の床が見える立体的な部屋へ変更し、床を約2倍に拡張。木製家具・パッチワークのベッド・織物ラグに意匠を統一し、クローゼット・鳥かご・額など7品、壁紙3柄、床3柄を追加。家具の回転と左右の壁への配置、拡大・画面移動に対応。既存のおかね・所持品・部屋ごとの配置座標は保持。

- はれ・くもり・あめ・ゆき・かぜと3時間ごとの天気予報を追加。屋外の雨粒・波紋・雪・風、春夏秋冬の草木の色、おうちの窓と天気のひとことが変わります。天候は見た目の変化だけで、おかね・移動・バトルに影響しません。

- 七夕・ハロウィン・お正月など、月替わりの年間イベント12種類を追加。各地で3つの遊びに参加して、月ごとの限定服・家具・デザをもらえます。年間予定の閲覧、毎年の参加、取得品と旧イベント記録の保持に対応。

- ぱぱ・ままの服、顔、髪型、色、小物、肌色を変更して保存できるように。歩く・手を振る・3人をなでる・手持ちの普段のごはんをあげるお世話と、自動お世話の切り替えを追加。おかねは自動使用しません。
- おうちの発言を話者に向いた吹き出しへ変更。満腹時は「はらぺん」「はらぱん」。古いセーブのおかね・所持品を保持して家族設定を補完します。

- 全体マップを地形のあるオリジナルの島へ刷新。海岸線・山・森・川・湖・街区・道路・交通ルートに9エリアを配置。地点タップ、拡大縮小、ドラッグ、2本指ズーム、現在地への移動、交通表示切り替えと各エリアの詳細図。プレイ位置やセーブは変えずに閲覧できます。

### 追加

- 春のさくらさんぽ・夏のほしあかりまつり・秋のどんぐりまつり・冬のゆきあかりまつりを追加。季節の名所3か所のスタンプで、限定の服4種・反応する家具4種・デザ4種を受け取れます。取得品は季節が変わっても残ります。
- 町のイベント看板と「おまつり」ボタン、季節に合わせた花びら・蛍・落ち葉・雪、対象の名所の飾りを追加。
- 平和台駅周辺の参考画像から、斜めの大通り・駅前商店街・住宅の路地・公園がある「平和台」を追加。港・空港と、電車・船・飛行機の無料移動も追加。
- 各エリアに噴水、水車、ブランコ、風車、灯台、クレーンなどの動く景観と寄り道を追加。！のあるものをタップすると反応します。全体地図に乗り場と遊べる場所を表示。
- 都会に「なかよし パズル」「そらの はいたつ」を追加。連鎖・フィーバーと、3人の交代・障害物・防御を楽しめます。既存4店もそのまま遊べます。
- お店9種類で専用BGM。設定で「のんびり・ふつう・むずかしい」を選べます。
- 全体マップ、川沿い公園、きらめきシティ、しおかぜビーチ、新しい姿の敵8種を追加。どこからでも3人で帰宅できる導線を追加。

- おうちに人間のぱぱ・まま、みまもり、会話・レア会話、仲裁できるけんか、空腹音を追加。ごじにガゥーの声。
- みんな辛いものが苦手。食後にデザを欲しがるようになり、デザやあまくちの食事も追加。
- 服22点・家具12点・壁紙4種・床3種、反応する家具を追加。高額・勝利数条件付きで別の部屋を2室購入可能。

### 変更

- 簡単なお店の報酬を抑え、複雑な新作と高難度の報酬を増加。バトルの基本コインを25%増やし、複数の敵には追加報酬。失敗・放置の評価×は報酬0。
- 戦闘メニューをコンパクトにし、技・道具を選んでも3人のHPが隠れない配置に修正。

- ver2 の開発を開始。タイトルと せっていの表示を ver 2.0.0-dev に更新。これまでのセーブはそのまま使えます。
