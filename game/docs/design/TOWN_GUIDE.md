# 町づくりの きまり（TOWN_GUIDE）

町（タウン・シティ・平和台・港・空港 など）を 作る／直すときの 共通の きまり。
具体的な 見本と 部品は [`towns/`](towns/) に ある（いまは 平和台 v0.2）。

## 1. 町の 骨組み

- **道の 格**を つける: 大通り（車道 4マス＋両がわの 歩道 2マス）→ 生活道路（車道 2マス＋歩道 2マス）→ 路地（アスファルト 2マス・側溝・白線、歩道なし）→ 歩く 道（コンクリート・土）。
- 行き止まりと 切れた 道を 作らない。道は 1つに つながる（道の 島 = 1）。町の はしで 終わる 道は、画面の そとへ つづくか、ワープに つなぐ。
- **区画**に 性格を つける（駅前・商店街・住宅地・公園・神社 など）。同じ 建物の 型を ならべない（1つの 型は 全体の 30% まで）。
- **目じるし**を 置く（駅・鳥居・商店街の アーチ・大きな 木・銭湯の えんとつ）。スマホ 1画面（約 11×24 マス）に かならず 1つ 入るように。

## 2. 見かたの きまり（3/4 見下ろし）

- 建物は 南の 面（正面）を 見せる。入口は 建物の 下の はし。だから 店は 東西の 通りの **北がわ** に 並べる。
- 高いものは 足もとの マスから 上へ はみ出して 描く。当たり判定は 足もとの マスだけ（大きな 木は 幹の 1マス）。
- 置く 順番は 足もとの y が 小さい ものから（奥 → 手前）。屋根・旗かざり・電線などの「上の層」は いちばん 最後。

## 3. 道の 描きかた（ベクター）

- 道は **中心線（直線と 円弧）＋ 幅** で 持つ。タイルの 並べかえで 斜めや カーブを 作らない（階段状の ギザギザに なる）。
- 描く 順番: 歩道 → 縁石 → 車道 → ロータリーの 島 → 隅切り（交差点の 角を 半径 1.5マスで まるく）→ 切り下げ（車の 出入り口）→ 路面表示。
- 日本の 道の きまりに 合わせる: 左側通行、ロータリーは 時計回り（乗り場は 外がわ）、横断歩道は 帯を 道の 向きに そろえる、信号の ない 横断歩道の 手前に ひし形、停止線は 横断歩道の 手前。
- 当たり判定・歩ける 判定は マス（マスの 中心が 道の 中なら 道）。

## 4. にぎやかさの めやす（`npm run audit:town` で 数える）

| めやす | 目標 |
| --- | --- |
| 小物の 密度（歩ける 100マス あたり。木・へい・背景を のぞく） | 8 以上 |
| 小物の 種類 | 20 以上 |
| 何もない 場所（半径 2マスに 何も ない 歩ける マス） | 10% 以下 |
| いちばん 多い 建物の 型の わりあい | 30% 以下 |
| 道の 島（つながっていない 道の かたまり） | 1 |
| ギザギザ（ななめだけで つながる 道の 角） | 0 |

- 道ぞい: 並木・街灯・電柱・信号は 歩道の **車道がわの 1マス**。歩く ところは 反対がわの 1マスを あける。
- 住宅地: 家の 前に 1マスの 前庭（塀・生け垣・門柱・カーポート・植木ばち）。路地に 電柱と 電線、角に カーブミラー。
- 商店街: 店ごとに のぼり・立て看板・店先の 品物。すずらん灯の 間に 旗かざり。
- 広い 芝生の 空白は 草むら・花・ハトで うめる（ただし 密度の 計算には 入れない）。

## 5. 確かめかた

1. `npm run check` と `npm test`
2. `npm run audit:town -- --check <町の id>`（めやすに 届かないと 失敗する）
3. 390×844 と 375×667 の スクリーンショットを 見本（`towns/<町>/img/phones.png`）と 並べて 見る
4. 建物の 入口・出口に ぜんぶ 歩いて 行けるか（テスト）
