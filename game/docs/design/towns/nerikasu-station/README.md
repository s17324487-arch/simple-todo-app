## 駅の性格

閑静な住宅街と通学路につながる、小さな生活の駅。セージ色の金属屋根、クリームの壁、木の柱と方杖、レンガの腰壁、銅色の雨どいを組み合わせました。中央の時計切妻、葉の駅章、和英の駅名が目印です。

駅員窓口は左、券売機は右。中央に2組のガラス入口と、その奥に見える改札。入口の前は空け、点字ブロックを横断歩道へつなぎます。ベンチと季節の花は待ち合わせの庭、掲示板と地図は案内の場所、自転車は駐輪場にまとめます。学校・保育園への案内、子供乗せ自転車、地域の掲示で暮らしの気配を出しています。

## 平和台と共通の描画ルール

1マス32px、南に入口を見せる3/4見下ろし。外輪郭はINK `#1F1D1B`、約1.0〜1.4px。内線は0.5〜0.9px。左上に明るい面、右下に影。屋根・柱・窓枠・設備を描き分けます。

ネリカス駅の足もとは14×5マス（448×160px）、bboxは `[-8,-47,470,179]`。屋根の上へのはみ出しと右下の影を含む画像を、足もとの448×160へ引き伸ばさないでください。描画位置は足もとの原点を維持し、地面と重なりの順序を分けます。

これは平和台駅の図形の置き換えではなく、新しい町のための原画です。平和台の元SVG・配置・実装は変更していません。

## 再生成

```sh
cd game
npm ci
npx playwright install chromium
node tools/town-design/nerikasu-build.mjs
```

画像なしのSVG／HTML／一覧の再生成は `--no-shots`。原画の正は `tools/town-design/nerikasu-assets.mjs` と `nerikasu-props.mjs`。出力SVGを手で変更せず、元コードから再生成します。フォントは既存の平和台と同じシステムの日本語フォントを使います。

再生成時に、32点のID重複、全原画のbboxからのはみ出し、不正値・外部参照、スマホでの表示と昼夜・分類・検索を検査します。通常のゲーム検査は `npm run check`、`npm test`。

## ゲームへ組み込む際の申し送り

- 現時点では `game/js/`、`index.html`、`sw.js`、マップ、セーブを変更していません。新しい駅へ入る機能、夜照明の時刻連動、列車走行、各小物の反応はまだ接続していません。
- 主人公3人は既存の `Chara.svg` を配置見本に使用しています。3人を分離させる新仕様はありません。
- 駅の既存ID、乗車料金、行き先、旧セーブ位置の救済、所持金を維持してください。
- 各原画のbbox・アンカーでWorldArtへ移し、SvgCacheは素材IDと昼夜などの有限キーにします。時間・座標をキーにしないでください。
- 14×5の駅舎、2×1のホーム単位ではなく8×2の庇など、実際の寸法を見て通路を設計してください。屋根の足もとと屋根の絵を混同しないこと。
- 原画集を確かめた上で、次の段階に駅前の道路・建物・小物の配置と本編への接続を扱います。
