# ネリカスタウン（MAP_DEFS.town）— 配置イメージどおりの 作り直し

オーナーの FB（2026-09-29）「ネリカスタウンを 添付の ような イメージの エリアに 再構築して ほしい。」への 対応（PR1: 町の 形）。
配置イメージ（練馬の 春日町の 地図に 道と 建物を かいた もの）の ならびを、1マス = 画像の 16px で マスに うつした（78×72 マス）。

- 旧来の 町から なくなった もの（オーナー「それは それで よい」）: ネリカスえき・かわの アトリエ・かわべの あずまや（`NerikasuLayout.REMOVED` に 理由）。
- 2つの コンビニ（ちがう 商品）と ファミレス びっくぽ（TOWN-NERI-02）、ガソリンスタンド・ゆうびんきょく・ひだまり アパート（TOWN-NERI-03）は 中に 入れる（下の「お店」）。掲示板の 依頼（TOWN-NERI-04）は 町の いりぐちの けいじばん（下の「いらいの けいじばん」）。

## 大きさと 道

- 78×72 マス。道は `TownRoads` の ベクター（ななめも なめらか）。当たり判定は マスの まんなか。
- 大通り（車道 4・歩道 1）・左の たての 道・よこの 道（中・下）・右の たての 道（上から 下まで）は 車道 2・歩道 1。ななめの 道 2本・よこの 道（ななめの 道の 下）・ななめの 道（3）・こみちは 車道 2・歩道 なし。
- 出入り口: 大通りの 北の はし（平和台へ）・右の 道の 北の はし（平和台へ）・右の 道の 南の はし（はらっぱへ）。平和台から くると 大通りの 北の はし、はらっぱから くると 右の 道の 南の はしに つく。
- 入口の まえから いちばん ちかい 道まで こみち（とちゅうで 建物に あたったら とまる）。右の 列の 家は 西の 右の 道へ、学校と 保育園は 南の 通学路へ。

## 公園・池・釣り

- 池は 3つ（大きい 公園 4×3・小さい 公園 3×2・東の 池）。どこでも `Fishing` の 町の 釣り場（`place: "pond"`）で つれる。水べは 4マス いじょう 歩いて いける。
- 公園の 遊具は 平和台と おなじ 原画（`park.*`）。車道には 小物を おかない（`free()`）。

## 住人

- 旧来の 34人（ID・会話は そのまま）を `NerikasuLayout.NPC_SPOTS` に おいた。村長は おまつりの けいじばん、ねこの ミントは 大きい 公園、クイズの 人は ふんすいの ひろば、かわべの 3人は 池の そば、ペンギンは ローリソン、ぶたは びっくぽ、うさぎは 洋服屋さん、ひつじは 家具屋さん、ねずみは パン屋さんの まえ。
- のこりは スマホの 画面（11×19 マス）の どこから 見ても 1人は いる ように くばった（`town-check` の「見えない 場所」が 0）。

## セーブ

- `Save.KEY`・`Save.SCHEMA` は そのまま。前の 町（64×68）で セーブした 位置が 建物や 池の 中に なったら、`TownRenewal.safePosition` が いちばん ちかい つながった 道へ うつす（おかね・もちもの・お店の きろくは そのまま）。
