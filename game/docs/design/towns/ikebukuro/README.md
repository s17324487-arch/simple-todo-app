# 池袋の 町（MAP_DEFS.city）— 配置イメージどおりの 作り直し

オーナーの FB（2026-09-29）「池袋の まちも より ハイクオリティに 実装しなおして ほしい。建物と 道路の 配置イメージを 送る。」への 対応。
配置イメージ（池袋 東口の 観光地図に 6つの 建物を かいた もの）の ならびを そのまま マスに うつした。

## 大きさと 道

- 96×58 マス。道は `TownRoads` の ベクター（ななめも なめらか）。当たり判定は マスの まんなか。
- なかどおり（y=20）は 上の 列の 店の まえを とおる 東西の 道。よこちょう（y=36・歩道なし）は 明治通りから K まで。
- 交差点の かどは まるく（直角は `fillets`、ななめは `ikeCorners` を 縁石の 線どうしの 円弧で 描く）。ななめの 横断歩道は しまを 道の むきに そろえる（`ikeCross`）。
- 町の はしで おわる 道は 画面の そとへ つづく（池袋は 電車だけで 来る 町・ワープなし）。

## めじるしと 小物

- いけふくろう（駅まえの 石の ふくろう・`ikebukuro.owl`）・まちあわせの とけい・ふんすい・点字ブロック・タクシー のりば・バス。
- サンシャイン60どおりの かんばん（`ikebukuro.pylon`）・のぼりの 街灯（`ikebukuro.bannerlamp`）・大きな 画面（`ikebukuro.vision`）・おはなやさんの ワゴン。
- 緑の大通りの いちょう（`nat.ginkgo`・木なので 小物の 数には 入れない）・ベンチ・街灯。
- 南北の 電車（`ikebukuro.train`・2へんせい。絵は 昼と 夜の 2つだけ）。
- 夜は 窓・街灯・画面・入口が あかるく なる（`IkebukuroTown.lights`）。

## なおしかた

1. 建物・道の 場所は `js/ikebukuro-town.js` の `BUILDINGS`・`ROADS`・`PEOPLE`。
2. 絵は `tools/town-design/ikebukuro-buildings.mjs` → `node tools/build-ikebukuro-town.mjs`（見本の 画像は `--shots`）。
3. `npm run check`（town-check: 旧ID・入口・古い セーブの 位置・密度・スマホの 画面／check-ikebukuro: 配置イメージの ならび・どの 入口にも 駅から いける・絵の 有限の キー）と スモーク（town-renewal・museum-visit・range-lobby・ikebukuro-*・district-travel）。

## セーブ

- `Save.KEY`・`Save.SCHEMA` は そのまま。町の 形が かわった ので、古い セーブの 位置が 建物の 中に なったら `TownRenewal.safePosition` が いちばん ちかい 歩道へ うつす（おかね・もちものは かわらない。town-check が 全マスで たしかめる）。
- なくなった もの: TownRenewal の よこむきの 線路の かざり（`city_railway`）→ 南北の 電車に かわった。あたらしい もの: `ike_koban`・`ike_walker0〜2`。
