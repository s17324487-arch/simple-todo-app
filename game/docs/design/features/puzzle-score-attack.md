# なかよしパズル：スコアアタック

オーナーの「大人向けにゲーム性を作り込み、参加料と得点による非売品の景品にする」という依頼に対応。シティの既存の入口と店員を使用する。お客さん・注文・店のレベル・コインの給与はこのパズルには使用しない。

## 遊ぶ流れと報酬

店内のララに話しかける → ルールと景品を確認 → 80コインで挑戦、または無料練習 → スタート → 時間切れで記録・景品を自動保存 → 受付またはおうち。

参加料はゲーム内コインのみ。80コインは、従来のクレープLv1を最高評価で1回遊んだ報酬（21×4＝84コイン）に近い。練習は本番と同じルールで、参加料・報酬・ベスト記録の更新がない。育成、装備、全体の難易度設定による得点補正はない。

| 得点 | 非売品の景品 | お部屋での特徴 |
|---:|---|---|
| 1,200 | 星しずくの結晶灯 | 多面体の結晶、真鍮の輪、光のまたたき |
| 4,000 | 月くらげの水族館 | アーチ型の水槽、くらげ、動く光 |
| 9,000 | 彗星のブランコ | 大きな三日月の座席、星の飾り |
| 16,000 | オーロラのグランドピアノ | 虹色のふた、鍵盤、ベンチのある大型家具 |
| 45,000 | なかよし銀河の天球儀 | 幅224（普通のイス36の約6倍）、3惑星、軌道の光 |

各景品は初回達成時に1個。下位の景品も同時に受け取る。抽選・再挑戦時の重複配布・現金やコインへの換金はない。全品 `rare: true / price: 0` で通常の販売リストから除外し、もようがえに追加する。通常時から光がまたたき、タップ中は輝きと動きが強まる。

## 盤面と形

6×6の同じ絵を縦・横に3個以上なぞる。斜めは不可。一つ前のマスへ戻すとなぞり直し。始点に戻る操作だけを輪として認める。色に加えて3人のキャラクター、星、月、ひし形で区別する。

| 形（上の行を優先） | 条件 | 効果 |
|---|---|---|
| カラーリング | 4個以上の閉じた輪 | 離れたマスも含め同じ絵をすべて消す |
| ライン | 4個以上の直線 | その行または列を消す |
| クロス | 5個以上、曲がり角1つ、両側が各2辺以上のL字 | 曲がり角の行と列を消す |
| スター | その他の7個以上の長い鎖 | 終点の周囲3×3も消す |
| チェイン | その他の3個以上 | なぞった部分を消す |

消える範囲と予想得点・実際に回復可能な秒数を指を離す前に表示。重力で落下・補充し、手詰まりは料金なしで自動シャッフル。手動シャッフルは5秒消費・コンボ解除、3回まで。

## スコア・時間・終盤の難しさ

- 開始45秒、残り時間の上限65秒、実プレイ180秒で必ず終了。
- なぞった数 `n`、実際に消した数 `c`、形のボーナス `b` として基本点は `7n² + 20c + b`。`b` は通常0、ライン80、クロス130、輪140、スター150。
- 3.5秒以内の消去でコンボ。倍率は `1 + min(10, combo−1) × .12`、最大2.2倍。
- 特殊形でフィーバーゲージ＋1、直前と違う特殊形で＋2。6以上で8秒間、得点1.6倍。延長秒数はフィーバーでも増えない。
- 段階 `k = min(5, floor(経過秒/30))`。時計の消費速度は `1 + .28k`。45秒・90秒経過時に補充される絵が4→5→6種類に増える。
- 1回の延長は `min(5, .45(n−2) + 形の延長) × .86^k`。形の延長は通常0、ライン1.4、クロス1.8、輪2、スター2.2秒。短い3個消去をゆっくり続けるだけでは時計に追いつかない。
- 時間はフレームごとの描画時間上限を使わず、実経過時間から計算。段階をまたぐ場合は分割して計算し、低FPSによる時間の引き延ばしを防ぐ。
- 一時停止・背景タブ・中断は盤面を隠して時計を止める。盤面、乱数状態、残り時間、コンボ、フィーバーを保存して同じ挑戦を続ける。

## バランス検証

`npm run balance:puzzle -- 200`。種は `i × 7919 (i=1..200)`。可視盤面だけを評価する4モデルを、ゲームと同じ `NakayoshiPuzzle` で各200回試行。補充される未来の絵は参照しない。数値は人間の実測達成率ではない。

| 操作モデル | 1手の基本思考秒＋追加ドラッグ | 得点10%点 | 中央値 | 90%点 | 最高点 | 平均プレイ秒 |
|---|---|---:|---:|---:|---:|---:|
| 3個消去中心 | 4.6秒 | 1,107 | 1,107 | 1,107 | 1,107 | 44.7 |
| 形を探す練習中 | 3.0秒＋長さ分 | 5,494 | 9,316 | 14,958 | 20,816 | 60.8 |
| 特殊形を使い分ける | 1.9秒＋長さ分 | 12,850 | 21,313 | 31,666 | 44,244 | 74.8 |
| 高速・長鎖を選ぶ | 1.1秒＋長さ分 | 38,106 | 50,812 | 63,952 | 81,926 | 100.2 |

追加ドラッグは3個を超えた1個ごとに0.12秒。探索範囲と評価式は `tools/puzzle-sim.mjs` に固定。3個モデルの同点は、3個を同じ間隔で消し、コンボ・特殊技を使用しないため。

この結果を受け、最上位の仮条件25,000点（高速モデルの達成率100%）を **45,000点** に変更。中級の特殊形モデルの今回の最高点より高く、高速モデルの中央値より低い位置にした。閾値変更はゲームの盤面・得点計算に影響しないため、上の得点分布は最終ルールにも適用される。最終閾値での厳密な達成率はシミュレーターの再実行で算出できる。最初の景品は3個消去だけでも操作が速くなれば到達でき、上位は形・コンボ・フィーバーの習得が必要。

## 調べたゲームと取り入れた考え方

- [Two Dots公式：四角を作る理由](https://dots.helpshift.com/hc/en/3-two-dots/faq/382-why-does-the-game-prompt-me-to-make-squares/)：閉じた形が同色全体の消去につながり、長さ以外の判断軸になる。本作は輪を明示的に閉じる操作と、形の使い分けによるフィーバーを採用。
- [G5公式：Match-3の仕掛け](https://support.g5.com/hc/en-us/articles/9192012634130-What-kind-of-mechanics-are-there-in-Match-3-mode)：列消去・範囲消去・同種全体消去を使い分ける。本作はなぞり方で即時発動し、範囲を事前表示する。
- [EA公式：Bejeweled Blitz](https://www.ea.com/games/bejeweled/bejeweled-blitz)：得点を高めるブーストと視覚的な特別感を調査。本作は形と連続操作でブーストを獲得し、家具の報酬は固定得点の達成に結び付ける。

盤面の絵・UI・家具はこのゲーム用のSVG/Canvasで新規作成。外部ゲームの素材は使用しない。

## 保存・実装・確認

`Save.KEY = pokapoka-town-save-v1`、SCHEMA 1を維持。新しい `puzzle: {best, plays, claimed, active, last}` を追加。既存 `shops.link` のレベル・評判・百分率のベスト記録は保持し、新しいスコアには流用しない。所持金・所持品・部屋はそのまま。

引き落としと進行中の盤面を同時保存。進行中の再開では課金しない。保存失敗時は引き落としを戻す。終了時は獲得品・履歴・ベスト・完了IDを同時保存し、同じ挑戦を再処理しても配布しない。終了保存が失敗した場合は配布を戻して再試行画面を表示。

- `js/puzzle-engine.js`：独立したルールと再現可能な乱数。
- `js/scene-puzzle.js`：受付、操作、時計、中断、保存、結果画面。
- `js/puzzle-prizes.js`：5品のデータ、部屋用立体SVG、光の描画。
- `tools/puzzle-check.mjs`：形、入力の不正、時間境界、シャッフル、フィーバー、手詰まり、旧セーブ、料金・景品の重複と保存失敗。
- `tests/smoke.mjs`：390×844 / 375×667の店員受付、実際のドラッグ、予告表示、中断・再読み込み、料金、景品、無料練習、部屋への配置。
- デバッグ：`PokaDebug.puzzleStart({practice,seed})`、`puzzleState()`、中断中のみ `puzzleBoard([...36値])`、実行中のみ `puzzleAdvance(秒)`。ブラウザ操作の検証は `puzzleClock(true)` で自動操作の待ち時間を除外し、時間計算は別途単体検証と実時計・FPS測定を行う。

Chromiumのスマホ寸法で自動検証。実機の指での手触り・長期プレイの達成率は、次のプレイフィードバックでさらに調整できる。
