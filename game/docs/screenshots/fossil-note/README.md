スモーク `fossil-note-*` で、次を たしかめて いる。

- `fossilGive` で 骨を もつ（ピッケルは まだ ない）。

- 10しゅの マス。ティラノサウルスは「ほね 2/8」、コンプソグナトゥスは「そろった！」、ほかの 8しゅは「？？？」。「あつめた ほね 4 / 63」。
