# すまほ（UI-01）

町の「おまつり」ボタンの かわりに 出る「すまほ」（`js/smaho.js`）の 見本。スモーク「smaho-390 / smaho-375」が とる 画像（`npm run test:full`）。

| ファイル | 中み |
| --- | --- |
| `smaho-390_home.png` / `smaho-375_home.png` | ホーム画面（とけい・日づけ・アプリ 10こ。うらないの あかい しるしは「きょうは まだ」） |
| `smaho-390_status.png` | ようす（3にんの カード。いままでの ≡ の「ようす」） |
| `smaho-390_event.png` | イベント（12か月の おまつり。いままでの「おまつり」ボタン） |
| `smaho-390_rally.png` | スタンプラリー（きせつの スタンプ／まいにち スタンプ） |
| `smaho-390_hint.png` | ひんと（いまの セーブから「つぎに できる こと」を えらぶ） |
| `smaho-390_fortune.png` / `smaho-375_fortune.png` | うらない（1にち 1かい。ラッキーの おみせは ほんとうに コイン 1.2ばい） |
| `smaho-390_map.png` / `smaho-375_map.png` | ちず（地点の タップ はんいは 44px いじょう） |
| `smaho-390_town.png` | 町（ひだり したに「すまほ」。おまつりボタンは ない） |
| `smaho-390_menu-help.png` | ≡（せってい・あそびかた だけ） |

- アプリの 中みは いままでの まどと おなじ ものを すまほの 画面に 入れて いる（`Menu.status`・`Menu.bag`・`Menu.dex`・`WorldAtlas.render`・`AnnualFestivals.open`・`Seasonal.open`・`DailyPlay.open`・`ShopRewards.open`）。
- 見た目の 参考: どうぶつの森の スマホ（ホーム画面に まるい 四角の アプリが ならび、タップで ひらく）。絵は すべて この ゲームの ために かいた もの。
