- コインの けいひんは 1にち 600コイン まで（メダルと たからばこ あわせて）。のこりが たりない ときは その 台は あそべない（コインを はらう まえに しらせる）。
- まえの けいひん（ほしの おおきな ソファ・ゆめいろ メリーゴーランド・うまーぼう・ぱいのみん・かんとりーまむまむ）は けいひん カウンターで コインと こうかん できる（セーブの もちものは そのまま）。
- 台の ようすは 台の id つきで のこす。ふるい セーブで いれかわった 台（0・2・3・5・7）の ようすは つかわず あたらしく ならべる。とちゅうだった 1かいが いれかわった 台なら 100コインを かえす（まえと おなじ 台 1・4・6 は つづきから）。セーブの 形式（`Save.SCHEMA`）は そのまま。
