# 食べ物の 名前と 絵（ART-06）

`js/food-art.js` で なおした 20しゅの まえ（main）と あと。`tools/check.mjs` は 食べ物ごとに じぶんの 絵が ある（ほかの 食べ物の 絵を かりない）ことを 見る。

| ファイル | 中み |
| --- | --- |
| `before-after.png` | 左が まえ・右が あと。ピーマン・やきざかな・デザ・アイス／ゼリー／タルト・あまくちカレー・たまごサンド・おやさいスープ・おまつりの デザ 12しゅ |

なおした わけ:

- ピーマン … りんごの 形を みどりに ぬった だけ だった → 3つの こぶと へた。
- やきざかな … なまの さかなに 見えた → おさらの 上で こんがり・やきめ・レモン。
- デザ・アイス／ゼリー … プリンの 絵を かりて いた。デザ・タルト … ショートケーキの 絵。たまごサンド … メロンパンの 絵。おやさいスープ … ぎゅうにゅうの 絵（`home-catalog.js` が 絵を かりて いた）。
- あまくちカレー … からい カレーと おなじ 絵 → きいろい ルウ・ハートの にんじん・はたの ピック。
- おまつりの デザ 12しゅ … おさらに おまつりの しるし（こいのぼり・お月さまと うさぎ・ツリー など）だった → かがみもち・まめの クッキー・ひしもち・さくらゼリー・かしわもち・しずくゼリー・ほしゼリー・はなびアイス・おつきみだんご・かぼちゃプリン・やきいも・いちごケーキ。
