# 「おへや」から床面積を2倍にする

「おへや」→「2ばいに ひろげる」→購入確認。各室1回、6,000コイン。
通常の480×360から640×540へ広がり、床面積は正確に2倍になります。
いま置いてある家具・壁紙・床・所持品を保持します。拡張した床へ家具を移動でき、別室にもそれぞれ購入できます。

再現（game/で実行）:

```sh
node tests/smoke.mjs --full --shots --only=おへやの2倍拡張
```

Playwright Chromium、端末ピクセル倍率2。390×844と375×667の両方で、旧セーブの再開・残高不足・購入キャンセル・6,000コインだけの支払・二重購入防止・広がった床へのドラッグ・未拡張の別室への切替・別室の拡張・保存と再開・表示拡大を確認します。
