# ころころ フルーツ（ネリカスタウンの パズルの おてつだい・MG-01 / MG-02）

オーナーの FB（2026-09-29）「ネリカスタウンに パズル系の お手伝いを。スイカゲーム的な パズルで、フルーツだけでなく ごじ・わんこ・がちゃの 顔も 降ってくる ゲームが よい」と、
（2026-09-30）「お手伝いの モードを 追加して。新しい モードは 実際の スイカゲームと 同じ ルールで スコアを 競う モードに。もも・メロン・スイカを がちゃん・わんこ・ごじに 置き換えて」への 対応。

- はこの 上から 玉を ゆびで おとす。おなじ もの どうしが くっつくと 1つ おおきく なる:
  さくらんぼ → いちご → みかん → りんご → なし → **がちゃん** → **わんこ** → **ごじ**（ごじ どうしは はじけて きえる）。
  おちてくるのは 小さい 4しゅ（おなじ 確率）。3人の かおは くっつけて つくる。点は くっつけた 2つの だんで 1・3・6・10・15・21・28・36（本物の スイカゲームと おなじ 三角数）。
- 「おてつだいする」の あとで モードを えらぶ。
  - **ちゅうもん モード**: おきゃくさん（4にん）が ほしい もの（なし・がちゃん・わんこ）が はこに できると とどく。はこの 中みは おきゃくさんが かわっても つづく。あふれると（ふちより 上に 2びょう）はこが からっぽに なって、その おきゃくさんは 30てん へる。がちゃん・わんこ・ごじで チップ。
  - **スコア モード**: 本物の スイカゲームと おなじ きまりで、あふれるまで とことん（時間の せいげん なし・はみだすと 0.5びょうで おしまい）。ハイスコアと ランキング（上から 5つ）・スコアに あわせて コインと ひょうばん。「もういちど」で すぐ また あそべる。
- かおの 玉が できると、その子が よろこぶ（ぴよ！・わん！・がおー！）。ごじ どうしが きえると 3人 みんなで。

## BGM の 出典

- 店内・おてつだいの 曲: R. シューマン「たのしい のうふ」（Album für die Jugend 作品68 だい10ばん・1848年）。作曲者は 1856年に なくなって いる ので パブリックドメイン。
- 楽譜: Mutopia Project #659（Peters 版に もとづく LilyPond 原本。清書 Philippe Hézaine・清書の ライセンスは CC BY-SA 2.5）から 音の たかさと ながさを 写した（`js/mg-korokoro.js` の `SONGS.shop_korokoro`）。
- 小節 1〜4（左手の メロディ）と 小節 9〜12（右手の メロディ）の 8小節。メロディ（mallet）は 小節 1〜4 を 1オクターブ 上げ、左手は そのまま（piano）。うらうちの 和音（epiano）は 小節 1〜4 が 楽譜の まま、9〜12 は かんたんに した。bass と ドラムは この ゲームの そえもの。
