# ころころ フルーツ（ネリカスタウンの パズルの おてつだい・MG-01）

オーナーの FB（2026-09-29）「ネリカスタウンに パズル系の お手伝いを。スイカゲーム的な パズルで、フルーツだけでなく ごじ・わんこ・がちゃの 顔も 降ってくる ゲームが よい」への 対応。

- はこの 上から 玉を ゆびで おとす。おなじ もの どうしが くっつくと 1つ おおきく なる:
  さくらんぼ → **わんこ** → いちご → **がちゃん** → **ごじ** → みかん → りんご → なし → もも → メロン → すいか（すいか どうしは はじけて きえる）。
  おちてくるのは 小さい 5しゅ（くだもの 2・3人の かお 3）。
- おきゃくさん（4にん）が ほしい くだもの（みかん・りんご・なし）が はこに できると とどく。はこの 中みは おきゃくさんが かわっても つづく。
- あふれると（ふちより 上に 2びょう）はこが からっぽに なって、その おきゃくさんは 30てん へる。もも・メロン・すいかで チップ。
- 2つの かおが くっつくと、カウンターの その子が よろこぶ（わん！・ぴよ！・がおー！）。
