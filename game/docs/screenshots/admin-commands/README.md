# 管理者用の隠しコマンド

開き方:

1. メニュー →「せってい」を開き、一番下までスクロール。
2. 「ぽかぽかタウン ver 2.0.0-dev」の表示を7回連続でタップ。間隔1.5秒以内、全体6秒以内。
3. 表示された「かんりしゃ コマンド」を押す。

コマンドは「おかねを99,999にする」「3人のHP/SP全回復」「おなか/ごきげん100」。確認画面で「じっこう」を選ぶと即時保存。所持金が99,999より多い場合も99,999へ設定され、確認文に変更前後の額を表示します。獲得コイン統計・レベル・持ち物・部屋配置は変えません。回復系はおうち・ワールドで使用できます。

解除状態は保存しません。タブを切り替える、メニューを閉じる、または再読み込みすると再び隠れます。

再現（game/で実行）:

```sh
node tests/smoke.mjs --full --shots --only=隠し管理者コマンド
```

390×844 / 375×667、端末ピクセル倍率2のChromiumで確認。通常時の非表示、6回では出ないこと、タップ間隔のリセット、7回で出ること、重複防止、確認中の連打防止、キャンセル、少ない/多い所持金の設定、即時保存とHUD更新、回復、既存の所持品・進行保持、タブ切替/メニューを閉じる/再読み込み時の非表示を実操作で検証します。
