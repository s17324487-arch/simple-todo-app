# 5属性のバトル

帰宅ボタンを戦闘から外し、Game.gotoでも敗北以外の家への移動を拒否する。全滅すると3人全員が回復して家に戻る。勝利・逃走・にげだまくんは戦闘前の場所に戻る。ボスからの逃走は従来どおり不可。おかねの減額は追加しない。

## 相性

火 → 草 → 岩 → 雷 → 水 → 火。矢印の先に1.5倍、逆方向は0.75倍、同属性とその他は1倍。味方の防御属性は使える属性と同じ（ごじ＝岩/火、がちゃん＝草、わんこ＝雷/水）。二属性で有利・不利が相殺したら1倍。二重弱点は作らない。通常攻撃・旧技の多く・トリオ攻撃は無属性。敵の攻撃は技指定の属性、指定がなければ敵自身の属性。

## 状態異常

| 属性 | 表示 | 効果 | 自分の番 |
|---|---|---|---|
| 火 | ひりひり | 開始時に最大HPの4%のダメージ。通常は上限20、ボスは12 | 3回 |
| 水 | びしょぬれ | すばやさ ×0.7（次のラウンドの順番に反映） | 3回 |
| 岩 | ぐらぐら | ぼうぎょ ×0.7 | 3回 |
| 草 | つるからみ | こうげき ×0.75 | 3回 |
| 雷 | びりびり | 25%で行動を1回休む。1つの状態につき最大1回 | 2回 |

同時に1種類まで。付与中の上書き・延長なし。自然回復後は2回の自分の番の間、再付与を防ぐ。ぼうぎょ・回復技・どうぐで解除でき、ぼうぎょ中は付与を防ぐ。戦闘不能と復活でも解除。眠りは従来の別効果として残る。ボスの付与率は半分、びりびりで休む率は12.5%。敵の新属性技の付与率は30%。

## 新技（既存の技は維持）

各行は Lv1 / 4 / 8 / 12 / 18 の順。SPは2〜12。全体攻撃は単体より威力・付与率を低めにしている。全技が属性攻撃と確率による状態異常を持つ。

| 属性・担当 | 5つの技 |
|---|---|
| 火・ごじ | ひのこ / ほのおの わ / ひの つめ / ほのおの おどり / おひさま ブレス |
| 岩・ごじ | こいし ころころ / いしの あられ / いわの こぶし / いわの とりで / やまの おとしもの |
| 草・がちゃん | わかば カッター / はなびら のまい / つるの ぎゅっ / もりの ささやき / まんかい ブーケ |
| 雷・わんこ | ちいさな いなずま / かみなり リレー / いなずま ダッシュ / ごろごろ あらし / きらめく らいこう |
| 水・わんこ | みずでっぽう / あわの シャワー / みずの やいば / おおなみ / いのちの しずく |

つるのぎゅっ・まんかいブーケ・いのちのしずくは実際に与えたダメージからHPを吸収。いわのとりでは3ラウンド防御を1.3倍にする。詳しい威力・付与率はbattle-elements.jsのデータで調整する。

## 戦闘曲

ボスならbattle_crown、最もレベルが高い敵がLv16以上または味方の平均より4以上高ければbattle_elite。それ以外は最もレベルが高い敵の属性に応じた5曲。複数の敵が同レベルならID順で決め、遭遇ごとに不用意に曲が変わらないようにする。

## 検証

`npm run check`に相性25組・25技の割当・19種類の敵・状態の解除/再付与/ボス上限・曲選択・セーブ互換を含める。ブラウザでは390×844 / 375×667で技を使い、状態回復・帰宅拒否・逃走先・HPの表示・保存再開を確認する。別シナリオで敵による全滅から3人の回復と帰宅を確認する。
