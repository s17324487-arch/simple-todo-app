# 難易度とコイン（ver2 開発中）

`node tools/balance.mjs` で実装と同じ式から比較表を出せる。基準はお店Lv1・全員◎・チップ/装備/ごきげん加算前。

| お店 | 1回の客数 | のんびり | ふつう | むずかしい |
| --- | ---: | ---: | ---: | ---: |
| クレープ | 4 | 56 | 84 | 128 |
| はな | 4 | 72 | 108 | 164 |
| パン | 4 | 92 | 144 | 216 |
| はいしゃ | 4 | 108 | 168 | 252 |
| そらのはいたつ | 3 | 282 | 432 | 648 |

簡単な注文選択より、記憶・タイミング・回避/交代を必要とするものの基準額を上げた。そらのはいたつは1客の作業時間が長いため3客にしている。既存店が最大7客になるLv5でも、新作の1回の総報酬が低くならない基準額にした。お店Lvが上がるごとに基準額を28%加算。評価×/△/○/◎の倍率は0/0.45/1/1.5。時間に余裕のある◎には従来同様チップが付く。

難易度は設定から選ぶ。のんびりは制限時間135%、敵の攻撃75%、報酬65%。ふつうは100%。むずかしいは時間80%、攻撃130%、報酬150%。開始時の設定を終了まで使い、途中変更で報酬だけ増えることを防ぐ。

バトルのコインは従来の125%。敵が2体ならさらに110%、3体なら120%。敗北・途中帰宅には報酬なし。レベルの経験値条件と既存セーブの所持金は変更しない。増築は4500/9000コインと10/30勝の両方が必要で、長期の目標として残す。

自動テストでは評価・難易度による報酬の順序、放置の無報酬、連鎖中断、障害物、防御、配達の完走を確認。実際のプレイヤーの所要時間や成功率による調整は今後も行えるよう、数値を `GameEconomy` に集約した。

## なかよしパズル（スコアアタック）

お客さん形式の給与を廃止し、参加料80コイン、無料練習、1,200 / 4,000 / 9,000 / 16,000 / 45,000点の非売品5品へ変更。全体の難易度設定や装備で有利にならない固定ルール。200盤面×4操作モデルの得点分布と調整根拠は[設計資料](design/features/puzzle-score-attack.md#バランス検証)。再現は npm run balance:puzzle -- 200。
