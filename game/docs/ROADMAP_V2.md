## M1. 安心して遊べるように

### [ ] V2-01 セーブの書き出し・読み込み（バックアップ）

セーブがブラウザの中にしかなく、機種変更やブラウザのデータ削除で消えるため。

- せってい画面に「セーブを かきだす」「セーブを よみこむ」を足す。
  - かきだす: セーブを文字列（JSON を base64 などにしたもの）にして表示し、コピーできる。可能なら `.txt` ファイルとしても保存できる。
  - よみこむ: 文字列を貼り付け（または ファイルを選択）→ 中身を確認して `Save.migrate()` を通してから置きかえる。
- 受け入れ条件:
  - 書き出した文字列を 別のブラウザで読み込むと、コイン・服・部屋・レベルが同じになる。
  - こわれた文字列・ほかのゲームのデータを読み込もうとすると、ひらがなのエラーが出て、今のセーブは変わらない。
  - 読み込む前に「いまの セーブは きえるよ。いい？」と確認する。
  - スモークテスト: 書き出し → はじめから → 読み込み → 元に戻る、のシナリオを足す。

### [ ] V2-02 実機での確認と修正

- iPhone（Safari）と Android（Chrome）で、[`HANDOFF_CHATGPT.md`](HANDOFF_CHATGPT.md) の「実機チェックリスト」を行い、見つかった問題を直す。
- 受け入れ条件: チェックリストの全項目が OK。直した内容を CHANGELOG に書く。
  （AI だけでは実機を触れないので、オーナーが確認した結果を渡して直してもらう）
