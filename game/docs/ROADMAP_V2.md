# ver2 ロードマップ

ver1（v1.0.0）のあとに作るものの一覧。**上から順に優先度が高い**。オーナーは自由に並べかえ・追加・削除してよい。

- 1つの項目 = 1つの PR が目安（大きい項目は「2-1」「2-2」のように分けてよい）。
- 着手するときは「受け入れ条件」をすべて満たすこと。あわせて [`AGENTS.md`](../../AGENTS.md) の「完了の条件」も満たす。
- 終わったら、項目の見出しの先頭の `[ ]` を `[x]` にし、PR 番号を書く。
- ver2 のテーマ（案）: **「まちが もっと にぎやかに、3人の まいにちが もっと たのしく」**

## M1. 安心して遊べるように

### [ ] V2-01 セーブの書き出し・読み込み（バックアップ）

セーブがブラウザの中にしかなく、機種変更やブラウザのデータ削除で消えるため。

- せってい画面に「セーブを かきだす」「セーブを よみこむ」を足す。
  - かきだす: セーブを文字列（JSON を base64 などにしたもの）にして表示し、コピーできる。可能なら `.txt` ファイルとしても保存できる。
  - よみこむ: 文字列を貼り付け（または ファイルを選択）→ 中身を確認して `Save.migrate()` を通してから置きかえる。
- 受け入れ条件:
  - 書き出した文字列を 別のブラウザで読み込むと、コイン・服・部屋・レベルが同じになる。
  - こわれた文字列・ほかのゲームのデータを読み込もうとすると、ひらがなのエラーが出て、今のセーブは変わらない。
  - 読み込む前に「いまの セーブは きえるよ。いい？」と確認する。
  - スモークテスト: 書き出し → はじめから → 読み込み → 元に戻る、のシナリオを足す。

### [ ] V2-02 実機での確認と修正

- iPhone（Safari）と Android（Chrome）で、[`HANDOFF_CHATGPT.md`](HANDOFF_CHATGPT.md) の「実機チェックリスト」を行い、見つかった問題を直す。
- 受け入れ条件: チェックリストの全項目が OK。直した内容を CHANGELOG に書く。
  （AI だけでは実機を触れないので、オーナーが確認した結果を渡して直してもらう）

## M3. 3人の まいにち・まちの くらし

### [ ] V2-08 まちの人の「おねがい」（クエスト）

- 町の人から小さなおねがい（例:「はらっぱの おはなを 3こ もってきて」「クレープを ◎ で 2かい つくって」）を受け、達成するとごほうび。
- メニューに「おねがい」一覧（受けている・達成済み）。
- 受け入れ条件:
  - おねがいのデータは `data.js` に表で持つ（`{ id, from, text, goal: { type, id, n }, reward }`）。
  - 進み具合はセーブに保存（`Save.fresh()` に `quests: {}` を足す。migrate で古いセーブにも入る）。
  - 同時に受けられるのは3つまで。達成時に会話とごほうび。
  - check.mjs に「おねがいの from（NPC）・goal・reward が実在するか」の検査を足す。

### [ ] V2-09 まいにちの たのしみ（ログインスタンプ・きょうの おすすめ）

- その日はじめて遊ぶと スタンプが1つ（7つで ごほうび）。
- 「きょうの おすすめ」のお店は 報酬が 1.2 倍。
- 受け入れ条件: 日付は `U.today()` を使う。端末の時計を戻しても1日に何回ももらえない（最後にもらった日より前の日付なら何もしない）。

### [ ] V2-10 なかよしイベント

- 3人の なかよし度が 30 / 60 / 100 になると、おうちで短いイベント（3人の会話と ちょっとした演出）が起きる。見たイベントは メニューで見返せる。
- 受け入れ条件: イベントは1回だけ。会話は ひらがな中心で、3人の性格（わんこ=リーダー、がちゃん=しっかり者のサポート、ごじ=やさしい力持ち）に合わせる。

### [x] V2-11 天気と季節 ✅

- 町・フィールドに 雨・雪 などの天気（見た目だけ。1日の中でゆっくり変わる）。季節（春夏秋冬）で 草の色・木・町の飾りが変わる。
- 受け入れ条件: 夜の町と同じく 20 FPS 以上（`PokaDebug.fps()`）。天気の粒は数を上限つきで使い回す。
- 実装：5種類の天候と3時間ごとの予報、四季の草木・既存のおまつり飾り、屋内除外、窓と会話。天気の粒は最大48個。
