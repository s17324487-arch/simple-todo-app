# ぽかぽかタウン 〜わんこ・がちゃん・ごじの なかよし生活〜

スマホ向けの ほのぼの育成・着せ替え・冒険ゲーム。
わんこ・がちゃん・ごじ の3人はいつも一緒に行動する（町でも、おうちでも、お店でも、バトルでも）。

## 遊び方（起動）

ビルド不要の静的サイト。`game/index.html` を開けば動く。

- **スマホで遊ぶ（おすすめ）**: GitHub Pages などで公開し、`https://<ユーザー名>.github.io/<リポジトリ名>/game/` を開く。
  ブラウザの「ホーム画面に追加」でアプリのように全画面で遊べる（PWA・オフライン対応）。
- **PCで試す**: `game/` フォルダで `npm start` を実行し、`http://localhost:8080/` を開く（Node.js 18 以上）。
  `index.html` をダブルクリックして直接開いても遊べる（その場合はオフラインキャッシュのみ無効）。

セーブはブラウザの localStorage に自動保存される（20秒ごと・画面を閉じたとき）。

## 操作

| 場面 | 操作 |
| --- | --- |
| 町・フィールド | 行きたい場所を**タップ**で移動（自動で道を探す）。**ドラッグ**するとその場にスティックが出る。人・看板・宝箱・ドアはタップで話す／調べる／入る |
| PCキーボード | 矢印キー / WASD で移動、Z・Enter・Space で調べる、X・Esc でメニュー |
| おうち | キャラをタップでなでる。下のボタンで ごはん・あそぶ・きがえ・もようがえ・ねる・おでかけ |
| もようがえ | 家具をドラッグで移動、タップで「はんてん」「しまう」。下のトレイから家具を置く／壁紙・床を変える |

## ゲームの流れ

1. **おうち（育成）** — おなか・ごきげんはリアル時間で少しずつ減る。ごはん（好物だと大喜び、苦手だと不機嫌）、なでる、あそぶ（かくれんぼ・ボールあそび）、ねる（HP/SP全回復）でお世話する。なかよし度が上がるとバトルの「なかよしトリオアタック」が溜まりやすくなる。
2. **着せ替え** — あたま・かお・くび・ふく・せなか の5部位、約45種類。服は体の形にぴったり合わせて描画され、歩き・ジャンプ・後ろ姿にも追従する。能力が上がる服や、お店のチップが増える服もある。ごじは体の色（ソフト／ダーク）も選べる。
3. **部屋作り** — 家具24種・壁紙8種・床6種。「いごこち」が高いほど ごきげんが減りにくい。
4. **お店のおてつだい（ミニゲームでコインを稼ぐ）** — たまごっちのプチプチおみせっち風。お客さんが来て注文 → タッチで作業 → ◎○△× で評価 → 代金とチップ → 評判が貯まるとお店がレベルアップ（最大Lv5。客数と難しさ・報酬が増える）。
   - **クレープやさん**: 注文のトッピングをのせる（Lv3以上は注文がすぐ消える記憶ゲーム）
   - **はいしゃさん**: 歯のばいきんをタップ、よごれはこする、むしばは長押し。健康な歯を叩くと痛がる
   - **パンやさん**: パンを選んでオーブンへ。メーターが「ふんわり／こんがり」の範囲で取り出す。トッピングの数も合わせる
   - **おはなやさん**: 注文の色と本数どおりに花を取り、リボンの色を選ぶ
5. **お買い物** — ようふくやさん（試着プレビュー付き）・かぐやさん・スーパー（食べ物・回復アイテム・能力が永久に上がるおかし）。
6. **冒険とバトル** — 町の南から ぽかぽかはらっぱ → どんぐりのもり → キラキラどうくつ へ。見えている敵に触れるとバトル。3人パーティのターン制で、たたかう・とくぎ（キャラごとに4〜5種）・どうぐ・ぼうぎょ・にげる、なかよしゲージ満タンでトリオアタック。勝つとコインと経験値（3人で共有）。どうくつの奥のボス「キングプルン」を倒すと王冠とトロフィーがもらえる（1日1回再戦可）。

時間帯（朝・夕方・夜）は実際の時計に合わせて町の色が変わり、夜は街灯がともる。

## 素材について

`assets/chara/` は受け取ったキャラ素材パックのSVGマスター（README.txt も同梱）。
全ポーズが idle_01 に対する変形（回転・伸縮・足の持ち上げ）で、表情は顔パーツの差し替えという構造になっているので、
`tools/build-chara.mjs` でこれを解析して `js/chara-data.js` を生成し、ゲーム内でポーズ×向き×表情×服をその場で合成している。

- 待機・歩き・ジャンプのアニメーションは素材README推奨の順番とタイミング（待機0.5秒、歩き8fps、idle_02→jump_01→land_01→idle_01）
- 横向きは顔パーツをずらした3/4ビュー、後ろ姿は顔を外してしっぽ等を手前に描いたもの（コードで生成）
- 服は胴体のパスで切り抜いて描くので、3人の体型の違いに自動で合う

素材SVGを差し替えたら次で再生成する:

```sh
node game/tools/build-chara.mjs
```

町の人・敵・家具・アイコン・タイルは、素材と同じ線の色（#1F1D1B）と太さで描いたオリジナル。BGMと効果音は WebAudio でその場で合成している（音声ファイルなし）。

## 開発

ver1 は完成（git タグ `v1.0.0`）。ver2 を開発中。**開発に参加する人・AI は、まずリポジトリ直下の [`AGENTS.md`](../AGENTS.md) を読むこと。**

| 文書 | 中身 |
| --- | --- |
| [`../AGENTS.md`](../AGENTS.md) | 作業ルール・コマンド・完了の条件（AI エージェントが自動で読む） |
| [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) | 設計書（しくみ・データの形・追加のしかた） |
| [`docs/ROADMAP_V2.md`](docs/ROADMAP_V2.md) | ver2 でやること（優先順・受け入れ条件） |
| [`docs/HANDOFF_CHATGPT.md`](docs/HANDOFF_CHATGPT.md) | ChatGPT（Codex）で開発を続ける手順 |
| [`CHANGELOG.md`](CHANGELOG.md) | 変更履歴 |

```sh
cd game
npm ci                                        # 初回だけ（テスト用の Playwright を入れる）
npx playwright install --with-deps chromium   # 初回だけ（テスト用のブラウザ）
npm run check      # 静的チェック（数秒・ブラウザ不要）
npm test           # 静的チェック + ブラウザでのスモークテスト（約1分）
npm run test:full  # 全シナリオ + スクリーンショット（約5分、tests/screenshots/）
npm start          # http://localhost:8080/ で遊ぶ（素材プレビューは /tools/preview.html）
```

PR を作ると GitHub Actions（`.github/workflows/game-test.yml`）が同じテストを自動で実行する。
`js/version.js` の版を `2.0.0` のような正式な版にして main にマージすると、`.github/workflows/release.yml` が タグと Releases ページを自動で作る。

## ファイル構成

```
game/
  index.html            起動ページ（js の読み込み順はここで決まる）
  manifest.webmanifest  PWA設定
  sw.js                 オフラインキャッシュ（キャッシュ名は GAME_VERSION と連動）
  package.json          開発用コマンド（npm run check / npm test など）
  CHANGELOG.md          変更履歴
  css/style.css         UIのスタイル
  icons/                アプリアイコン
  assets/chara/         キャラ素材（SVGマスター）
  docs/                 設計書・ver2ロードマップ・引き継ぎ手順
  tools/
    build-chara.mjs     素材SVG → js/chara-data.js 変換
    check.mjs           静的チェック
    serve.mjs           ローカルサーバー
    preview.html        素材プレビュー（開発用）
  tests/smoke.mjs       ブラウザでのスモークテスト（Playwright）
  js/
    version.js     ゲームのバージョン（GAME_VERSION）
    chara-data.js  （自動生成）素材の構造データ
    chara.js       キャラ合成・着せ替えの描画
    art.js         町の人・敵・家具・アイコンの絵
    tiles.js       地面タイル・木・建物
    maps.js        マップ（町は手描き、外の世界は生成）
    data.js        服・食べ物・家具・敵・とくぎ・お店のデータ
    save.js        セーブ・育成パラメータ・ステータス計算
    sound.js       効果音とBGM
    ui.js / menu.js / shop.js / dressup.js   画面UI
    scene-*.js     タイトル・町/フィールド・おうち・バトル
    minigames.js   お店のミニゲーム4種
    main.js        起動・ループ・入力・シーン切り替え
    debug.js       テスト・開発用の PokaDebug
```

アイテムや敵を増やすときは `js/data.js` に1行足せばよい（服は `wear` に `js/chara.js` の描画関数名を指定）。
くわしい手順は [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) の「追加のしかた」。
