3キャラ ゲーム素材パック
========================
キャンバス : 512x512px 透過PNG（sprite_*.png は 6コマ横並び 3072x512）
基準点     : 足元中央 (256, 492)
身長比     : wanko 1.00 / goji 1.00 / gachan 0.90（全ファイル同一縮尺）
線         : #1F1D1B、512pxで約10px
命名       : {キャラ}_{状態}_{番号}.png / {キャラ}_face_{表情}.png
色違い     : goji = dark / soft（フォルダ別）
アニメ推奨 : 待機 idle_01<->idle_02 各0.5秒
             歩き idle_01 > walk_01 > idle_01 > walk_02 を 8fps
             ジャンプ idle_02 > jump_01 > land_01 > idle_01
SVG は拡大縮小しても劣化しないマスター。128px以下が必要ならSVGから書き出すこと。
