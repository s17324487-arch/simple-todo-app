# LINE れんけい（UI-126）オーナーの せっていの てじゅん

わんこ・がちゃん・ごじ から、つないだ LINE に おしらせが とどく しくみ。
オーナーの 指示（2026-10-14）「③にしたいので許可する。」で 入れた（AGENTS.md 4-10 の 例外）。**ぜんぶ むりょうの はんいで うごく。**

```
ゲーム（ブラウザ） ──ばんごう・あいことば・3人の おなか/ごきげん──▶ GAS（オーナーの Google）──push / reply──▶ LINE
                                                          ▲                                    │
                                                          └──── Webhook（ともだち ついか・トーク）──┘
```

- ゲームが おくる もの: 6もじの ばんごう・あいことば（ゲームが ランダムに つくる）・3人の [おなか, ごきげん] の すうじ だけ。
- GAS に のこる もの: ばんごう・あいことばの ハッシュ・LINE の userId・さいごの ようすと じこく・おしらせの かず（スクリプト プロパティ）。
- ゲームの セーブには LINE の userId は はいらない。
- むりょうの はんい: LINE の コミュニケーションプラン（つき 200通）を こえない ように、GAS が ぜんぶで つき 190通・ひとり つき 31通・1にち 1通・21じ〜9じは おくらない ように おさえる。へんじ（reply）は 200通に かぞえない。

## 0. ひつようなもの

- LINE の アカウント（スマホの LINE で よい）
- Google アカウント（Gmail で よい）

## 1. LINE 公式アカウントを つくる（むりょう）

1. <https://entry.line.biz/> を ひらき、「LINE公式アカウントの開設」→ LINE の アカウントで ログイン。
2. アカウント名（例: ぽかぽかタウン）・業種などを いれて つくる。プランは なにも しなければ むりょうの「コミュニケーションプラン」。

## 2. Messaging API を つかえる ように する

1. <https://manager.line.biz/>（LINE Official Account Manager）で 1 の アカウントを えらぶ。
2. みぎうえの「設定」→ ひだりの「Messaging API」→「Messaging APIを利用する」。
3. プロバイダーを つくる（なまえは あとから かえられない。例: pokapoka-town）。

## 3. 「応答設定」を かえる（だいじ）

Official Account Manager の「設定」→「応答設定」で:

- 「Webhook」を **オン**
- 「応答メッセージ」を **オフ**（オンの ままだと LINE の じどうの へんじも いっしょに でる）
- 「あいさつメッセージ」は **オフ** が おすすめ（ともだち ついかの あいさつは GAS が ごじの ことばで おくる）

## 4. チャネルアクセストークン（ひみつ）を つくる

1. <https://developers.line.biz/console/>（LINE Developers）に おなじ LINE で ログイン。
2. 2 で つくった プロバイダー → チャネルを えらぶ →「Messaging API設定」タブ。
3. いちばん したの「チャネルアクセストークン（長期）」の「発行」を おす。でてきた ながい もじを コピー。
   - **これは ひみつ**。チャット・GitHub・ゲームの ファイルには かかない。つぎの 5-4 で GAS に だけ いれる。

## 5. GAS（Google Apps Script）を つくる

1. <https://script.google.com/> →「新しいプロジェクト」。なまえを「ぽかぽかタウン LINE」などに。
2. はじめから ある `コード.gs` の なかみを ぜんぶ けして、この フォルダの [`Code.gs`](Code.gs) を まるごと はりつけて ほぞん（💾）。
3. ひだりの ⚙「プロジェクトの設定」→ したの「スクリプト プロパティ」→「スクリプト プロパティを追加」:
   - プロパティ: `LINE_TOKEN`
   - 値: 4 で コピーした チャネルアクセストークン → 「スクリプト プロパティを保存」
4. ひだりの「エディタ」に もどり、うえの 関数の えらぶ ところで `setup` を えらんで「実行」。
   - はじめては「承認が必要です」→ じぶんの Google アカウントを えらぶ →「このアプリは Google で確認されていません」と でたら「詳細」→「（安全ではないページ）に移動」→「許可」。じぶんで つくった スクリプト なので だいじょうぶ。
   - これで 1じかん ごとの おしらせ（`tick`）が うごく ように なる（ひだりの ⏰「トリガー」に 1つ でる）。
5. みぎうえの「デプロイ」→「新しいデプロイ」→ ⚙ で「ウェブアプリ」:
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - 「デプロイ」→ でてきた「ウェブアプリ」の URL（`https://script.google.com/macros/s/…/exec`）を コピー。
6. ブラウザで その URL を ひらいて `{"ok":true,"app":"pokapoka-line","ver":1}` と でれば OK。

## 6. LINE に GAS を つなぐ（Webhook）

1. LINE Developers の チャネルの「Messaging API設定」→「Webhook設定」→「Webhook URL」に 5-5 の URL を いれて「更新」。
2. 「Webhookの利用」を **オン**。
3. 「検証」で 302 などの エラーが でる ことが ある（GAS は いちど べつの ばしょへ みちびく ため）。じっさいに とどくかは つぎで たしかめる。
4. スマホの LINE で この 公式アカウントと ともだちに なる → ごじから「ともだちに なってくれて ありがとう！」が くれば OK。
   こない ときは GAS の ひだりの「実行数」で `doPost` が うごいたか みる。

## 7. ゲームに つなぎさきを いれる（ひみつでは ない 2つ）

- GAS の ウェブアプリの URL（5-5）
- ともだち ついかの URL: Official Account Manager の「ホーム」→「友だちを増やす」→「友だち追加ガイド」の URL（`https://lin.ee/…`）

この 2つを Claude に つたえる（または じぶんで [`../js/online-config.js`](../js/online-config.js) の `lineUrl`・`lineFriend` に かいて main に いれる）。
**チャネルアクセストークンは つたえない・かかない。**

## 8. あそぶ ひとの つなぎかた（ゲームの なか）

1. ≡ → せってい →「LINE と つなぐ」→ 18さい いじょうの 同意。
2. 6もじの ばんごうが でる →「LINE で ともだちに なる」→ LINE の トークに ばんごうを おくる → ごじたちが「つながったよ」と へんじ。
3. ゲームで「つながったか たしかめる」。
4. 6じかん いじょう あそばないと、9じ〜21じの あいだに 1にち 1かい おしらせが くる（おなかが すいた子・ながく あって いない ときは さみしい ことば）。
5. LINE で なにか おくると「さいごに あそんだのは ○じかん まえ」と へんじ（むりょう）。
6. やめる: ゲームの「LINE を はなす」か、LINE で「やめる」と おくる。ともだちを やめても はずれる。

## コードを かえた とき

GAS の エディタで `Code.gs` を はりなおして ほぞん →「デプロイ」→「デプロイを管理」→ ✏ →「バージョン」を「新バージョン」→「デプロイ」。
URL は かわらない（「新しいデプロイ」を つくると URL が かわるので、そのときは 6 と 7 を やりなおす）。
